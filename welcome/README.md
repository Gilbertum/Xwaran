# Xwaran Welcome — приветствия и автоматические шотауты Twitch

Бесплатная статическая панель, работающая через **Twitch EventSub WebSockets + Twitch Helix API**. Не требует Streamer.bot, сервера, Twitch-пароля или Client Secret.

## Ссылка

При включённом GitHub Pages из ветки `main` и папки `/ (root)`:

**https://gilbertum.github.io/Xwaran/welcome/**

> Адрес существует только если GitHub Pages включён и публикация успешно завершилась. Проверь `Settings → Pages` репозитория `Gilbertum/Xwaran`.

## Подключение Twitch (один раз)

1. Открой сайт и нажми «Настройки Twitch» — откроется отдельная страница `settings.html`.
2. Перейди на [Twitch Developer Console](https://dev.twitch.tv/console/apps).
3. Зарегистрируй приложение: **Public** (не Confidential). Название: например `Xwaran Welcome`.
4. В `OAuth Redirect URLs` укажи **точно** тот адрес, который покажет панель в блоке подключения. Если страница доступна по указанной выше ссылке, это `https://gilbertum.github.io/Xwaran/welcome/` (включая завершающий слеш).
5. Скопируй **Client ID** (это публичный идентификатор приложения) в панель. **Client Secret не копируй и никому не передавай**.
6. Нажми «Войти через Twitch». Проверь, что открыт твой аккаунт `Xwaran`, а затем разреши `user:read:chat`, `user:write:chat` и `moderator:manage:shoutouts` (последнее нужно для кнопки Follow во время эфира).
7. Добавь зрителей и включи нужные правила. Изначально все шаблоны отключены.
8. Открой главную страницу сайта и нажми «▶ Запустить автоматику» — в эфире или когда канал офлайн. Держи вкладку открытой всё время эфира, не усыпляй браузер/ПК.
9. Проверь работу с другого аккаунта Twitch, который есть в списке и которому назначено активное приветствие.

## Особенности и ограничения

- Приветствие срабатывает **на первое замеченное панелью сообщение** выбранного зрителя, а не на его вход в чат. Если зритель написал до запуска панели, сайт не знает об этом.
- Одно приветствие выбранному зрителю за текущую запущенную сессию. После остановки и повторного запуска начинается новая сессия. При перезагрузке страницы сессия также заканчивается.
- Сайт не работает после закрытия вкладки. Для полностью автономной фоновой работы нужен сервер/Worker + постоянный канал получения событий Twitch.
- С версии v1.2 приветствия работают во время эфира и офлайн, если в чате появляются сообщения. Кнопка запуска не зависит от статуса трансляции.
- Панель не обновляет токены автоматически: Twitch может потребовать повторного входа после истечения токена.
- Данные правил, Client ID и журнал отправок хранятся в **локальном хранилище браузера** на этом устройстве; синхронизации между браузерами нет. Экспортируй правила в JSON для резервной копии.
- Доступность Twitch в разных сетях/странах может различаться. Возможно, потребуется доступ к Twitch Developer Console и API.
- Одновременный запуск двух вкладок в Chrome/Edge блокируется Web Locks API; при отсутствии поддержки не запускай приложение в двух вкладках.
- Отправка идёт **от авторизованного Twitch-аккаунта**, а не от стороннего бота.

## Безопасность

- Никогда не вставляй токены, секреты или пароли в GitHub.
- OAuth токен хранится только в **sessionStorage** текущей вкладки браузера, не в репозитории, и очищается кнопкой «Отключить».
- Всё происходит в браузере напрямую с официальными доменами `id.twitch.tv`, `api.twitch.tv`, `eventsub.wss.twitch.tv`.
- Сайт не имеет собственной базы данных или удалённого сервера.
- GitHub Pages публичен: текст и исходный код сайта доступны всем. **Не сохраняй приватные тексты/идентификаторы в коде сайта**. Приветствия, добавленные через интерфейс, не отправляются на GitHub.

## Версия 1.2 (офлайн-чат и отдельные настройки)

- `settings.html`: адрес Redirect URI, Client ID, вход/выход Twitch перенесены с главной страницы.

## Версия 1.3 (автоматические шотауты)

- Отдельный раздел «Шотауты» на главной странице (`#shoutouts`). Переключение между «Приветствиями» и «Шотаутами» не закрывает EventSub WebSocket.
- Автоматическое срабатывание **при первом увиденном сообщении** выбранного Twitch-стримера, а не по факту открытия чата или входа в список зрителей. Только явно включённые правила. Никто из остальных пользователей не рекламируется автоматически.
- Примеры из известных коллабов `Hell_Fox_X`, `PsPuer`, `Gretel_RS` и `L0rinel` добавлены **выключенными**, не влияют на 22 существующих приветствия Twir.app.
- Во время собственного эфира и при разрешении `moderator:manage:shoutouts` выполняется `POST /helix/chat/shoutouts` — в Twitch появляется собственная карточка с кнопкой Follow. Twitch ограничивает нативные шотауты: **1 раз в 2 минуты, 1 раз для одного стримера в 60 минут**. Сайт помнит историю нативных шотаутов в localStorage, а если Twitch отказывает/ограничивает — пытается отправить обычный текст со ссылкой.
- Офлайн всегда отправляется текстовое сообщение от авторизованного аккаунта с прямой ссылкой `https://www.twitch.tv/LOGIN` и пользовательским шаблоном `{user}`, `{login}`, `{url}`. Ссылка автоматически добавляется, даже если её забыли в шаблоне.
- Не чаще одного шотаута в 90 секунд (настраивается 60/90/120), не чаще одного шотаута одному стримеру в 30 минут. Очередь и журнал событий. Учитываются ограничения обычного чата.
- Если включён шотаут определённого стримера, отдельное обычное приветствие ему **не дублируется**. Остальные приветствия не затронуты.
- Настройки шотаутов и история хранятся в браузере отдельно от приветствий. Есть экспорт/импорт JSON. Создание нового стримера по умолчанию выключено.
- Используется **тот же публичный Client ID** и тот же OAuth Redirect URI. Чтобы выдать **новое** разрешение для Twitch Follow, открой страницу настроек и нажми «Войти через Twitch» повторно; пароль, Client Secret и токен вручную не требуются.
- Для автоматической работы по-прежнему нужно держать вкладку главной страницы открытой. Отдельный сервер не нужен. Сайт не заявляет, что определяет «всех стримеров» автоматически: это невозможно надёжно установить по одной реплике в чате.

## Версия 1.4 — приветствие и шотаут в одной карточке (актуально)

- Разделы «Приветствия» и «Шотауты» объединены в один список **«Зрители и реакции»**. У каждого Twitch-ника две независимые галочки. В карточке редактируются оба текста одновременно. Можно включить **приветствие**, **шотаут** или **оба действия**.
- Если включены оба, первое сообщение запускает оба действия; они не подавляют друг друга. Во время эфира приветствие — текст, шотаут — встроенный Twitch Follow (при наличии разрешения и без кулдауна). Офлайн — два отдельных сообщения (приветствие и ссылка) с паузой для защиты от спама.
- **Без потери данных:** v1.4 продолжает читать и сохранять прежние ключи `xwaran_welcome_rules_v1` и `xwaran_welcome_shoutouts_v1` из localStorage. Персональные тексты, включения/выключения и прежний список из 22 пользователей остаются на месте. Один ник, присутствующий в обоих старых списках, показывается один раз.
- В карточке можно настроить оба текста независимо и выключить обе реакции, не стирая их. Кнопка удаления удаляет *обе* реакции (с подтверждением).
- **Резервная копия:** одна кнопка экспортирует оба списка в одном JSON (`version:2, rules, shoutouts`); импорт принимает этот формат, а также файлы v1.0–v1.3 только с `rules` или только с `shoutouts` (при этом второй список сохраняется).
- Адрес сайта и OAuth Redirect URL **не меняются**. Дополнительных приложений и токенов не требуется. Twitch-настройки остаются на отдельной странице.
- Срабатывание остаётся на **первое сообщение, замеченное после запуска панели**, не на появление зрителя в списке. Панель не работает, если вкладка закрыта.
